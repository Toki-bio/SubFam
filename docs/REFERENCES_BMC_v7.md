## (d) Problems found in the text and in the [AUTHOR] list

1. **MeShClust2 has no peer-reviewed paper.** It exists as the bioRxiv preprint of James & Girgis 2018 (ref. 24). The
   author list's "Girgis 2022 MeShClust v3" is in **BMC Genomics** 23:423, not Bioinformatics. The text uses "MeShClust" in
   Background and "MeShClust2" in Table 1 and Availability; the README says v3 was built but not run. Suggest: cite 5 at
   Background, 24 at "MeShClust2 (…; Girgis lab)" and drop "Girgis lab" from the sentence; cite 25 only if a sentence says
   v3 is the published successor.
2. **Konkel et al. 2015** is in Genome Biol Evol 7:2608 (the [AUTHOR] list gives no journal). It reports 343 sequenced
   insertions (322 unique); GenBank KT305395–KT305737 is exactly 343 accessions, consistent. The text's 316 is fine as the
   subset used, but the reason for 316 of 322 is not stated in v7.
3. **TEtrimmer is described inaccurately.** v7: "start from a genome and treat one locus at a time". The TEtrimmer README
   says it works per input TE consensus ("For each input consensus sequence, TEtrimmer automatically performs BLASTN
   search, sequence extraction, extension…"), with the genome required and a consensus library optional since v1.7.3.
   Suggest "one family (consensus) at a time"; the same wording recurs in "Relationship to existing tools" ("curates a
   library per locus").
4. **Bains & Temple-Smith 1989** (in the [AUTHOR] list) is not cited anywhere in the v7 text. The paper argues that B2
   contains subfamilies from 71 copies; a natural anchor is the Example 1 sentence on B2 names interleaving. Otherwise drop
   it.
5. **Repbase** is named in the text ("Repbase names") but is missing from the [AUTHOR] list; added as ref. 15.
6. **PartTree** and **MAGUS** and **Linclust** are named or implied in the text but missing from the [AUTHOR] list; added
   as refs 11, 26 and 4. MMseqs2 as an identity *clusterer* is Linclust (2018), not the 2017 search paper; cite both or
   only 4.
7. **Dfam 4.0** (Declarations) has no database paper; Storer et al. 2021 describes releases 3.0–3.3. Keep ref. 12 and give
   the release in the text ("Dfam release 4.0, https://dfam.org").
8. **"over 90 % of L1 copies are 5′-truncated"** (Example 2) carries no citation and none of the listed papers was checked
   for that figure. Either cite a source that states it or give the share measured in the chr4 input.
9. **COSEG** has no publication; the GitHub README names Hubley, Siegel and Smit as current authors and credits Price for
   the original code. The text's description of what COSEG requires was not checked against its documentation.
10. **Order with the prior-use block.** "The steps that follow" sits between Table 1 (ref. 24/25) and "Relationship to
    existing tools" (MAGUS), so the chosen prior-use papers take the numbers after 25 and MAGUS moves to the end;
    Vassetzky 2021 keeps 16.
11. Year checks: Khan et al. (epub Dec 2005, issue 2006) and PASTA (epub Dec 2014, issue 2015) are correctly cited with the
    issue year. Author-year citations in v7 (Price 2004, Konkel 2015, Vassetzky 2021) match their records.
12. The author's own name appears as "Sergey A" in the 2024 Ere and 2025 B2-RNA papers and "Sergei A" elsewhere; check
    consistency with the ORCID record.

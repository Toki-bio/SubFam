# COSEG 0.2.4 read at the source level (coseg.c, runcoseg.pl, preprocessAlignments.pl)

Read 2026-10-08. Not read: postprocess.pl, refineConsSeqs.pl, buildCpGAdjustedConsensus. The same text, with the SINEderella/peel comparison, is in the owner's Claude Docs doc "Alu subfamily definitions and how they are told apart" (artifact https://claude.ai/artifact/U5kNLaQtKsZByEy5sr6fRD, sections 3A and 8A).

- Flow: up to 10 rounds of {best pair (or triple with -t) in any subfamily -> split -> EM re-fit -> prune}; then single mutations; MST tree; at most 400 subfamilies (MAXS).
- Pair search: 5 states per site (A,C,G,T,deletion); first site >= minDist (10), second >= minDist before it; a state present in any subfamily consensus at that position is skipped; a state or pair carried by fewer than minCount copies is skipped; CpG transitions (C<->T before G, G<->A after C) skipped at both sites; two deletion states refused (DISALLOW_DASHDASH); z-score >= 3.0 pre-filter; P < 0.001 after Bonferroni factor 0.5 (L-d-m)(L-d-m+1) 16 (594,048 at L=282, minDist 10, i.e. raw P < 1.7e-9); then a local 2-way EM must reproduce both mutations; then the worst P over the union with every other subfamily.
- Single mutations: deletions refused (DISALLOW_INDEL), sigma threshold = -invNormal(0.001 / (L*4*400)) = 5.87 at L=282 (400 = MAXS constant).
- IUB bases are replaced by rand()%4 (default seed); lowercase consensus positions are disabled with -d.
- Prune: merge below minCount, merge at distance < 2, test pairs by ascending distance with a union P and merge if not significant, then Kruskal agglomeration.
- FINDING (verified by running an instrumented copy): in compute_siegel_pvalue and the tri version, n, n1, n2 are int, so (n1 / n) and 4 / 3 are integer divisions; p1_3sigma = p2_3sigma = 0 and cTerm = 1 (printed on the Konkel data: n=295, n1=140, n2=71). With floating division and Price's scale (n=480,000, n1=n2=3,300) cTerm would be about 1.34. A copy with the division fixed gave identical assignments on the 295 Konkel copies (-m 50/10/5) and on Price's 4,000-copy sample (-m 50). Not reported to the authors; effect elsewhere unknown. -k (Price's model) uses double arithmetic with a fudge capped at 4/3. On the Konkel copies at -m 5, -k gave 3 leaves and the default model 2.
- preprocessAlignments.pl: copies must start within maxEdgeGap (5) of the window start and end within it of the window end.
- No COSEG publication was found; the README cites Price 2004. No benchmark of COSEG found.

Peel (SINE-discriminator peel_features.py) vs this, from its code: accepts a group on a carriage gap >= 0.35 (features = (position, char incl. gap) carried by 5..50 % of the consensuses, Jaccard >= 0.45 blocks of >= 3 features, group = consensuses carrying >= 60 % of the block); no null model, no CpG rule found; the 0.85/0.70 "best" rule lives in pairsurvey.py (SPLIT: frac_var <= 0.25 and best >= 0.80; MERGE: frac_var >= 0.60 and best < 0.70), a post-hoc pair classifier the peel does not call; a single multi-column indel can form a block alone; REALIGN_FIRST/LATER only change a log message (it re-aligns every round).
